# SiteForge

Landing page institucional para SiteForge, estudio digital de Mendoza.

## Stack
- HTML semántico
- CSS responsive
- JavaScript vanilla
- Animaciones con IntersectionObserver

## Desarrollo local
Abrí `index.html` en el navegador o serví la carpeta con cualquier servidor estático.
